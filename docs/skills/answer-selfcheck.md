# 回答诊断自查清单

生成最终回答前逐条自查；发现任何一条不满足，先修正再输出。回答被用户质疑「不对 / 编造」时，也按本清单逐条排查。

## 逐条清单

1. **直接回答**：第一句就回答了用户问的问题，没有用背景铺垫拖延；问题问金额就先给金额，问时间就先给时间。
2. **数字一致**：金额、日期、编号、公司名与资料**逐字一致**（金额单位万元；日期不自行换算格式时区）。
3. **引用到位**：引用了某条资料就必须标 `[参考资料N]`；引用了联网结果标 `[网页N]` 并给出链接；两类引用不混排。
4. **不编造**：资料里没有的项目名、金额、日期、资质条件一律不写；宁可写「资料中未见」。
5. **缺口说明**：资料不足以回答时，明确说缺什么（缺哪个表 / 哪段时间的数据 / 哪个字段），并给出可行的下一步（换个关键词检索、查另一张表、联网搜索）。
6. **口径注明**：做了聚合统计（求和、计数、排名）时，注明统计口径（哪张表、哪个时间字段、是否去重、是否含空值）。
7. **结构清晰**：超过 3 条信息用列表；长回答先给结论再给依据；不写空话套话。

## 常见病因对照

- 「答非所问」→ 第 1 条失败：重读问题，找出真正的疑问词（多少 / 哪些 / 谁 / 何时）。
- 「数字对不上」→ 第 2 条失败：回原文逐字核对，警惕预算与中标金额混用、万元与元混用。
- 「像编的」→ 第 4 条失败：检查每个专有名词和数字是否都能指回一条具体资料。
