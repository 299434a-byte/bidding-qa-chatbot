# 招投标法规速查

回答法规类问题（期限、保证金、评标、公示）时先读本技能；引用法条要写明出处，拿不准的条文如实说明「以官方文本为准」。

## 《招标投标法》及实施条例要点

- **公告期限**：依法必须招标的项目，资格预审公告或招标公告发布之日起至投标截止，最短不得少于 **20 日**（潜在投标人编制文件需要合理时间）。
- **投标保证金**：不得超过招标项目估算价的 **2%**，且最高不超过 **80 万元**；投标有效期结束后退还。
- **开标**：开标时间与投标截止时间为**同一时刻**；开标地点为招标文件预先确定的地点；由招标人主持，邀请所有投标人参加。
- **评标委员会**：为 **5 人以上单数**，其中技术、经济等方面的专家不得少于成员总数的 **2/3**。
- **中标候选人公示**：依法必须招标的项目，中标候选人公示期不得少于 **3 日**。
- **中标通知书**：对招标人和中标人具有法律效力；中标人放弃中标或拒签合同的，投标保证金不予退还（给招标人造成的损失可追偿）。

## 《政府采购法》要点

- **公开招标**是政府采购的主要采购方式；达到公开招标数额标准的项目不得以其他方式规避。
- **邀请招标**适用情形：货物或服务具有特殊性、只能从有限范围供应商处采购；采用公开招标方式的费用占总采购比例过大。
- **竞争性磋商 / 询价**：适用情形与程序以《政府采购法实施条例》及财政部配套办法为准，回答时注明具体方式的法定条件。

## 引用规范

- 法条数字（日期、比例、金额上限）必须与本技能一致，不得凭印象改写。
- 用户问「本地实践与法规是否一致」时，先引用法规口径，再说明知识库中的实际公告情况，两者分开表述。
