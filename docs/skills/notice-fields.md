# 招标公告字段解读

bidding_notices 表（招标公告）各字段的含义与解读口径，回答公告类问题前先读本技能。

## 字段清单

| 字段 | 含义 | 解读口径 |
| --- | --- | --- |
| project_code | 项目编号 / 采购项目编号 | 如「ZFCG-2024-0312」，引用时原样给出，不要改写分隔符 |
| project_name | 项目名称 | 与公告标题可能不完全一致，以本字段为准 |
| budget_amount | 预算金额 | **单位：万元**（数据库内已是万元，不是元）。回答时写「XXX 万元」，不要自行换算成元 |
| purchaser | 采购人 / 招标人 | 全称引用，不要简称为「甲方」 |
| agency | 采购代理机构 | 为空时说明该公告为采购人自采，不要编造代理机构 |
| publish_date | 公告发布日期 | 格式 YYYY-MM-DD，回答写「YYYY 年 M 月 D 日」 |
| bid_deadline | 投标文件递交截止时间 | 精确到分钟的按分钟写；只到日期的不要补时分 |
| project_nature | 采购方式 | 公开招标 / 竞争性磋商 / 询价 / 单一来源等，原文引用 |
| qualification | 投标人资格要求 | 常含注册资金、资质等级、业绩要求；逐条列出，不要合并概括丢条件 |
| construct_period | 工期 / 服务期限 | 注意单位（日历天 / 月） |

## 易混口径

- 「预算金额」≠「中标金额」：bidding_notices 只有预算；实际中标金额在中标公告或 bidding_project 表，不要把预算说成中标价。
- 「投标截止时间」≠「开标时间」：法规上两者应为同一时刻，但公告若分开写了，按公告原文分别引用。
- 同一项目编号可能对应多个包（分包采购），金额是分包预算时要写明是哪个包。
